# 毫欧表硬件电路设计

## 1. 恒流源电路
```
方案A: LM334恒流源
- 简单可靠，温度补偿
- 通过电阻设置电流: I = 227μV / R_set

方案B: 运放+MOS管
- 精度更高，可数字控制
- 使用DAC设置电流值
```

## 2. 四线测量接口
```
测试夹具:
I+  ----[电流源]----> 被测电阻
I-  <----[电流回路]--- 被测电阻
V+  ----[高阻输入]----> 被测电阻
V-  <----[高阻输入]--- 被测电阻
```

## 3. 差分放大电路
```
方案A: INA226/INA229 (推荐)
- 集成高精度差分放大+ADC
- I2C接口，直接读取电压/电流
- 分辨率: 2.5μV

方案B: 运放差分放大器
- OP07/OP27低噪声运放
- 增益: 100-1000倍可调
- 输出接MCU的ADC
```

## 4. MCU选型
- STM32F103: 12位ADC，成本低
- STM32F4: 12位ADC，性能强
- ESP32: 12位ADC，带WiFi/蓝牙

## 5. 校准方法
1. 零点校准: 短路测试端，记录零点偏移
2. 满度校准: 使用标准电阻(100mΩ)校准增益
3. 多点校准: 10mΩ, 50mΩ, 100mΩ, 500mΩ
