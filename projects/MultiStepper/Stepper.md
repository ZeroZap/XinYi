# 步进电机基础原理及常用型号驱动详解

## 一、步进电机基础原理

### 1. 什么是步进电机

步进电机是一种将电脉冲信号转换为角位移或线位移的电机。每输入一个脉冲信号，电机就转动一个固定的角度（称为步距角），因此可以通过控制脉冲数量来精确控制位置。

```text
┌─────────────────────────────────────────────────────────────────┐
│                      步进电机工作原理                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│    脉冲信号          步进电机            机械运动                │
│   ┌──┐┌──┐         ┌──────┐                                    │
│   │  ││  │ ──────► │      │ ──────► 角位移 (旋转)              │
│   └──┘└──┘         │  M   │         或                         │
│    ↑               │      │         线位移 (配合丝杆)           │
│    │               └──────┘                                    │
│  脉冲数 = 步数                                                  │
│  脉冲频率 = 转速                                                │
│                                                                 │
│  公式: 转动角度 = 脉冲数 × 步距角                                │
│        转速(RPM) = 脉冲频率 × 60 / 每圈步数                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                    ┌─────────────┐                              │

│               N ───┤  │  S  │   ├─── S                         │
│                    │  │     │   │                              │

### 3. 步进电机分类

```text
┌─────────────────────────────────────────────────────────────────┐
│                     步进电机分类                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  按结构分类:                                                     │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                                                         │   │
│  │  1. 永磁式 (PM - Permanent Magnet)                      │   │
│  │     • 转子为永磁体                                       │   │
│  │     • 步距角大 (7.5°~15°)                               │   │
│  │     • 成本低，扭矩小                                     │   │
│  │     • 典型: 28BYJ-48                                    │   │
│  │                                                         │   │
│  │  2. 反应式/可变磁阻式 (VR - Variable Reluctance)         │   │
│  │     • 转子为软磁材料 (无永磁体)                          │   │
│  │     • 步距角小，精度高                                   │   │
│  │     • 无保持扭矩                                         │   │
│  │                                                         │   │
│  │  3. 混合式 (HB - Hybrid)                                │   │
│  │     • 结合PM和VR优点                                     │   │
│  │     • 步距角小 (0.9°~1.8°)                              │   │
│  │     • 扭矩大，精度高                                     │   │
│  │     • 典型: NEMA17, NEMA23, NEMA34                      │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  按绑组分类:                                                     │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                                                         │   │
│  │  1. 单极性 (Unipolar) - 5线/6线                         │   │
│  │     ┌───────────────────┐                               │   │
│  │     │    A相    B相     │                               │
│  │     │   ┌─┴─┐  ┌─┴─┐   │                               │
│  │     │   │   │  │   │   │                               │
│  │     │  A1  A2 B1  B2   │                               │
│  │     │   └─┬─┘  └─┬─┘   │                               │
│  │     │    COM   COM     │  ← 中心抽头接电源              │
│  │     └───────────────────┘                               │   │
│  │     • 驱动简单，只需单向电流                             │   │
│  │     • 扭矩利用率约50%                                    │   │
│  │                                                         │   │
│  │  2. 双极性 (Bipolar) - 4线                              │   │
│  │     ┌───────────────────┐                               │   │
│  │     │    A相    B相     │                               │
│  │     │   ┌───┐  ┌───┐   │                               │   │
│  │     │   │   │  │   │   │                               │   │
│  │     │  A+  A- B+  B-   │                               │   │
│  │     └───────────────────┘                               │   │
│  │     • 需要H桥驱动，电流双向                              │   │
│  │     • 扭矩利用率100%                                     │   │
│  │     • 同尺寸扭矩更大                                     │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4. 步进电机驱动模式

```text
┌─────────────────────────────────────────────────────────────────┐
│                    步进电机驱动模式                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 整步驱动 (Full Step)                                        │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  步序    A+    A-    B+    B-    转子位置                │   │
│  │   1      +     -     0     0      0°                    │   │
│  │   2      0     0     +     -     90°                    │   │
│  │   3      -     +     0     0    180°                    │   │
│  │   4      0     0     -     +    270°                    │   │
│  │                                                         │   │
│  │  特点: 步距角 = 电机标称步距角 (如1.8°)                  │   │
│  │        每圈200步 (1.8°电机)                             │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  2. 半步驱动 (Half Step)                                        │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  步序    A+    A-    B+    B-    转子位置                │   │
│  │   1      +     -     0     0      0°                    │   │
│  │   2      +     -     +     -     45°                    │   │
│  │   3      0     0     +     -     90°                    │   │
│  │   4      -     +     +     -    135°                    │   │
│  │   5      -     +     0     0    180°                    │   │
│  │   6      -     +     -     +    225°                    │   │
│  │   7      0     0     -     +    270°                    │   │
│  │   8      +     -     -     +    315°                    │   │
│  │                                                         │   │
│  │  特点: 步距角 = 标称步距角/2 (如0.9°)                    │   │
│  │        每圈400步，运行更平滑                             │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  3. 细分驱动 (Microstepping)                                    │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                                                         │   │
│  │  原理: 通过PWM控制线圈电流，产生正弦波形                  │   │
│  │                                                         │   │
│  │       电流                                              │   │
│  │        ↑    A相电流                                     │   │
│  │        │   ╱╲    ╱╲                                    │   │
│  │        │  ╱  ╲  ╱  ╲                                   │   │
│  │        │ ╱    ╲╱    ╲                                  │   │
│  │   ─────┼──────────────→ 步数                           │   │
│  │        │╲    ╱╲    ╱                                   │   │
│  │        │ ╲  ╱  ╲  ╱   B相电流                          │   │
│  │        │  ╲╱    ╲╱                                     │   │
│  │                                                         │   │
│  │  细分等级:                                              │   │
│  │  ┌──────────┬──────────┬──────────┬──────────┐        │   │
│  │  │ 细分数   │ 步距角   │ 每圈步数 │ 精度提升 │        │   │
│  │  ├──────────┼──────────┼──────────┼──────────┤        │   │
│  │  │ 1 (整步) │ 1.8°     │ 200      │ 1x       │        │   │
│  │  │ 2 (半步) │ 0.9°     │ 400      │ 2x       │        │   │
│  │  │ 4        │ 0.45°    │ 800      │ 4x       │        │   │
│  │  │ 8        │ 0.225°   │ 1600     │ 8x       │        │   │
│  │  │ 16       │ 0.1125°  │ 3200     │ 16x      │        │   │
│  │  │ 32       │ 0.05625° │ 6400     │ 32x      │        │   │
│  │  │ 64       │ 0.028°   │ 12800    │ 64x      │        │   │
│  │  │ 128      │ 0.014°   │ 25600    │ 128x     │        │   │
│  │  │ 256      │ 0.007°   │ 51200    │ 256x     │        │   │
│  │  └──────────┴──────────┴──────────┴──────────┘        │   │
│  │                                                         │   │
│  │  优点: 运行平滑、噪音低、振动小、定位精度高              │   │
│  │  注意: 细分越高，对驱动器要求越高                        │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5. 步进电机关键参数

```text
┌─────────────────────────────────────────────────────────────────┐
│                   步进电机关键参数                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 步距角 (Step Angle)                                         │
│     • 每个脉冲转动的角度                                        │
│     • 常见值: 0.9°, 1.8°, 7.5°, 15°                            │
│     • 每圈步数 = 360° / 步距角                                  │
│                                                                 │
│  2. 保持扭矩 (Holding Torque)                                   │
│     • 通电静止时抵抗外力的能力                                  │
│     • 单位: N·cm, kg·cm, oz·in                                 │
│     • 1 kg·cm ≈ 9.8 N·cm ≈ 13.9 oz·in                         │
│                                                                 │
│  3. 额定电流 (Rated Current)                                    │
│     • 每相线圈的额定工作电流                                    │
│     • 单位: A (安培)                                            │
│     • 驱动器电流设置不应超过此值                                │
│                                                                 │
│  4. 相电阻 (Phase Resistance)                                   │
│     • 每相线圈的直流电阻                                        │
│     • 单位: Ω (欧姆)                                            │
│     • 影响发热和效率                                            │
│                                                                 │
│  5. 相电感 (Phase Inductance)                                   │
│     • 每相线圈的电感值                                          │
│     • 单位: mH (毫亨)                                           │
│     • 影响高速性能 (电感越小，高速性能越好)                     │
│                                                                 │
│  6. 矩频特性 (Torque-Speed Curve)                               │
│     ┌─────────────────────────────────────┐                    │
│     │ 扭矩                                 │                    │
│     │  ↑                                  │                    │
│     │  │ ████                             │                    │
│     │  │ █████████                        │                    │
│     │  │ █████████████                    │                    │
│     │  │ █████████████████                │                    │
│     │  │ █████████████████████            │                    │
│     │  └──────────────────────────→ 转速  │                    │
│     │     低速区    中速区    高速区       │                    │
│     └─────────────────────────────────────┘                    │
│     • 转速越高，扭矩越小                                        │
│     • 选型时需考虑实际工作转速                                  │
│                                                                 │
│  7. 空载启动频率 (Max Starting Frequency)                       │
│     • 空载时能直接启动的最高脉冲频率                            │
│     • 超过此频率需要加减速控制                                  │
│                                                                 │
│  8. 空载运行频率 (Max Running Frequency)                        │
│     • 空载时能稳定运行的最高脉冲频率                            │
│     • 需要通过加速达到                                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2. 脉冲生成方法

/*============================================================================
 * 脉冲生成方法示例代码
 *============================================================================*/

/*----------------------------------------------------------------------------
 * 方法1: GPIO软件翻转 (简单但占用CPU)
 *----------------------------------------------------------------------------*/
void stepper_pulse_gpio(uint32_t steps, uint32_t delay_us)
{
    for (uint32_t i = 0; i < steps; i++) {
        GPIO_SetBits(STEP_PORT, STEP_PIN);      // 高电平
        delay_microseconds(delay_us / 2);
        GPIO_ResetBits(STEP_PORT, STEP_PIN);    // 低电平
        delay_microseconds(delay_us / 2);
    }
}

/*----------------------------------------------------------------------------
 * 方法2: 定时器中断 (推荐，不占用CPU)
 *----------------------------------------------------------------------------*/
volatile uint32_t g_step_count = 0;
volatile uint32_t g_target_steps = 0;

void TIM2_IRQHandler(void)
{
    if (TIM_GetITStatus(TIM2, TIM_IT_Update)) {
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
        
        if (g_step_count < g_target_steps) {
            // 翻转脉冲引脚
            GPIO_ToggleBits(STEP_PORT, STEP_PIN);
            
            // 每两次翻转算一个脉冲
            static uint8_t toggle = 0;
            if (++toggle >= 2) {
                toggle = 0;
                g_step_count++;
            }
        } else {
            TIM_Cmd(TIM2, DISABLE);  // 停止定时器
        }
    }
}

void stepper_move_steps(uint32_t steps, uint32_t speed_hz)
{
    g_step_count = 0;
    g_target_steps = steps;
    
    // 设置定时器周期 (频率 = speed_hz * 2，因为需要翻转两次)
    uint32_t period = SystemCoreClock / (speed_hz * 2) - 1;
    TIM_SetAutoreload(TIM2, period);
    TIM_SetCounter(TIM2, 0);
    TIM_Cmd(TIM2, ENABLE);
}

/*----------------------------------------------------------------------------
 * 方法3: PWM输出 (最高效，硬件自动生成)
 *----------------------------------------------------------------------------*/
void stepper_pwm_init(void)
{
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStruct;
    TIM_OCInitTypeDef TIM_OCInitStruct;
    
    // 定时器基本配置
    TIM_TimeBaseStruct.TIM_Prescaler = 72 - 1;  // 72MHz / 72 = 1MHz
    TIM_TimeBaseStruct.TIM_Period = 1000 - 1;   // 1MHz / 1000 = 1kHz
    TIM_TimeBaseStruct.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStruct);
    
    // PWM配置 (50%占空比)
    TIM_OCInitStruct.TIM_OCMode = TIM_OCMode_PWM1;
    TIM_OCInitStruct.TIM_OutputState = TIM_OutputState_Enable;
    TIM_OCInitStruct.TIM_Pulse = 500;  // 50%占空比
    TIM_OCInitStruct.TIM_OCPolarity = TIM_OCPolarity_High;
    TIM_OC1Init(TIM2, &TIM_OCInitStruct);
}

void stepper_set_speed(uint32_t speed_hz)
{
    uint32_t period = 1000000 / speed_hz;  // 周期 (微秒)
    TIM_SetAutoreload(TIM2, period - 1);
    TIM_SetCompare1(TIM2, period / 2);     // 50%占空比
}

/*----------------------------------------------------------------------------
 * 方法4: DMA传输 (超高速，适合复杂波形)
 *----------------------------------------------------------------------------*/
// 预定义脉冲序列
uint16_t pulse_buffer[1000];

void stepper_dma_init(void)
{
    DMA_InitTypeDef DMA_InitStruct;
    
    // 填充脉冲缓冲区 (交替高低电平)
    for (int i = 0; i < 1000; i++) {
        pulse_buffer[i] = (i % 2) ? STEP_PIN : 0;
    }
    
    // DMA配置
    DMA_InitStruct.DMA_PeripheralBaseAddr = (uint32_t)&GPIOA->ODR;
    DMA_InitStruct.DMA_MemoryBaseAddr = (uint32_t)pulse_buffer;
    DMA_InitStruct.DMA_DIR = DMA_DIR_PeripheralDST;
    DMA_InitStruct.DMA_BufferSize = 1000;
    DMA_InitStruct.DMA_PeripheralInc = DMA_PeripheralInc_Disable;
    DMA_InitStruct.DMA_MemoryInc = DMA_MemoryInc_Enable;
    DMA_InitStruct.DMA_PeripheralDataSize = DMA_PeripheralDataSize_HalfWord;
    DMA_InitStruct.DMA_MemoryDataSize = DMA_MemoryDataSize_HalfWord;
    DMA_InitStruct.DMA_Mode = DMA_Mode_Normal;
    DMA_InitStruct.DMA_Priority = DMA_Priority_High;
    DMA_Init(DMA1_Channel1, &DMA_InitStruct);
    
    // 定时器触发DMA
    TIM_DMACmd(TIM2, TIM_DMA_Update, ENABLE);
}

/*============================================================================
 * 梯形加减速算法实现
 *============================================================================*/

typedef struct {
    int32_t target_pos;         // 目标位置
    int32_t current_pos;        // 当前位置
    float current_speed;        // 当前速度 (steps/s)
    float max_speed;            // 最大速度
    float accel;                // 加速度 (steps/s²)
    float decel;                // 减速度
    uint32_t accel_steps;       // 加速步数
    uint32_t decel_steps;       // 减速步数
    uint32_t total_steps;       // 总步数
    uint32_t step_count;        // 已执行步数
    uint8_t state;              // 0:加速 1:匀速 2:减速 3:完成
} trapezoidal_t;

void trapezoidal_plan(trapezoidal_t *tp, int32_t target, 
                      float max_spd, float acc, float dec)
{
    tp->target_pos = target;
    tp->max_speed = max_spd;
    tp->accel = acc;
    tp->decel = dec;
    
    int32_t delta = target - tp->current_pos;
    tp->total_steps = (delta > 0) ? delta : -delta;
    
    // 计算加速到最大速度需要的步数: s = v²/(2a)
    float accel_steps_f = (max_spd * max_spd) / (2.0f * acc);
    float decel_steps_f = (max_spd * max_spd) / (2.0f * dec);
    
    if ((accel_steps_f + decel_steps_f) >= tp->total_steps) {
        // 三角形曲线 (无法达到最大速度)
        float peak = sqrtf((2.0f * acc * dec * tp->total_steps) / (acc + dec));
        accel_steps_f = (peak * peak) / (2.0f * acc);
        decel_steps_f = tp->total_steps - accel_steps_f;
        tp->max_speed = peak;
    }
    
    tp->accel_steps = (uint32_t)accel_steps_f;
    tp->decel_steps = (uint32_t)decel_steps_f;
    tp->step_count = 0;
    tp->current_speed = 0;
    tp->state = 0;
}

// 在定时器中断中调用，返回下一步的间隔时间(微秒)
uint32_t trapezoidal_next_interval(trapezoidal_t *tp)
{
    if (tp->state == 3) return 0;  // 已完成
    
    uint32_t decel_start = tp->total_steps - tp->decel_steps;
    
    switch (tp->state) {
        case 0:  // 加速阶段
            tp->current_speed = sqrtf(2.0f * tp->accel * (tp->step_count + 1));
            if (tp->current_speed >= tp->max_speed) {
                tp->current_speed = tp->max_speed;
                tp->state = 1;
            }
            if (tp->step_count >= tp->accel_steps) {
                tp->state = 1;
            }
            break;
            
        case 1:  // 匀速阶段
            if (tp->step_count >= decel_start) {
                tp->state = 2;
            }
            break;
            
        case 2:  // 减速阶段
            {
                uint32_t remaining = tp->total_steps - tp->step_count;
                tp->current_speed = sqrtf(2.0f * tp->decel * remaining);
                if (tp->current_speed < 100) tp->current_speed = 100;  // 最小速度
            }
            break;
    }
    
    tp->step_count++;
    
    if (tp->step_count >= tp->total_steps) {
        tp->state = 3;
        return 0;
    }
    
    // 计算脉冲间隔
    return (uint32_t)(1000000.0f / tp->current_speed);
}
