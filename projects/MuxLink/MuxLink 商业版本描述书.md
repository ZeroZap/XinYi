# MuxLink 产品故事与由来

## 1. 命名缘起

MuxLink 的名字源于 **Multiplexer（多路复用器）** 与 **Link（连接）** 的组合。它精准地传达了产品的核心设计理念：

- **Mux**：代表多路复用、资源整合。CH32H417 拥有 95 个 GPIO、多个独立 USB 控制器、双核处理器，通过智能的资源管理，将众多功能融合在一个小巧的设备中。
- **Link**：象征连接——连接 PC 与硬件、连接数字与物理世界、连接开发者与目标设备。

## 2. 从痛点出发

在嵌入式开发中，工程师常常需要携带多种工具：调试器、逻辑分析仪、示波器、信号发生器、协议转换器、电源分析仪……每个工具都有独立的硬件和软件，不仅成本高昂，而且携带不便、学习曲线陡峭。

MuxLink 的诞生就是为了解决这一痛点：**用一个设备替代多个工具**，让开发者能够在一台设备上完成调试、测量、分析和控制。

## 3. 设计理念

- **软件定义硬件**：同一套硬件，通过 PC 端软件或板载 Lua 脚本，可以随时变身为不同的仪器。
- **模块化扩展**：通过 OpenClaw 接口，用户可以连接各种外设模块，自由组合功能。
- **高性能基础**：基于 CH32H417 的双核 400MHz RISC-V 处理器和 USB 3.0 5Gbps 接口，为高速数据采集和实时控制提供保障。
- **开发者友好**：从 Arduino 兼容层到自研 OSAL 框架，再到 AI 辅助开发，降低入门门槛，提升开发效率。

## 4. 品牌口号

- **主口号**：*One Link, Infinite Links*（一个连接，无限可能）
- **副口号**：*Your Hardware Lab in a Dongle*（装在U盘里的硬件实验室）

## 5. 愿景

让硬件开发像写软件一样简单。MuxLink 不仅是调试工具，更是连接创意与实现的桥梁。

# MuxLink 商业版本描述书

## 1. 产品定位

MuxLink 是一款面向嵌入式开发者、硬件工程师、创客、教育机构和科研实验室的 **多功能硬件调试与开发平台**。它以 USB 3.0 为核心接口，集成了 CMSIS-DAP 调试器、高精度电流分析仪（μA 到 A）、逻辑分析仪、协议转换器、可编程电源、Lua 脚本引擎、LTDC 高清显示、TF 卡存储和以太网连接，并通过 OpenClaw 接口提供丰富的 I/O 扩展能力。

## 2. 目标市场与客户

| 客户类型     | 典型应用场景                 | 需求特征                             |
| :----------- | :--------------------------- | :----------------------------------- |
| 嵌入式工程师 | 固件开发、调试、功耗优化     | 需要高效调试工具，追求集成化、便携化 |
| 硬件工程师   | 电路调试、信号分析、电源测试 | 需要高精度测量和多种分析功能         |
| 创客/极客    | 原型验证、DIY 项目           | 追求易用性、扩展性和性价比           |
| 高校实验室   | 教学实验、课程设计           | 需要一机多用，降低设备采购成本       |
| 中小企业     | 产品研发、产测工装           | 需要稳定可靠、可定制化的工具         |

## 3. 产品规格（商业版本）

### 3.1 硬件规格

| 项目       | 参数                                                         |
| :--------- | :----------------------------------------------------------- |
| 主控       | CH32H417（双核 RISC-V @400MHz + 150MHz）                     |
| 内存       | 896KB SRAM，960KB Flash                                      |
| USB        | USB 3.2 Gen1（5Gbps）+ USB 2.0 FS（12Mbps）独立接口          |
| 调试器     | CMSIS-DAP v2（支持 SWD/JTAG，调试速度 >10MHz）               |
| 虚拟串口   | 2 路完整 CDC（每路带中断端点）                               |
| 电流测量   | 双 INA229，20-bit 分辨率，测量范围 0.1μA ~ 10A               |
| 可编程电源 | 支持 USB PD 输入（5-20V），板载可调输出（1.8V-5V）           |
| 显示       | 2.4 英寸 240×240 RGB LCD，电容触摸                           |
| 存储       | TF 卡插槽（支持 FatFS），板载 QSPI Flash（8MB）              |
| 网络       | 百兆以太网（内置 PHY）                                       |
| 扩展接口   | OpenClaw 40pin（引出 27 个 GPIO，可配置为 ADC/DAC/PWM/UART/I2C/SPI） |
| 尺寸       | 100mm × 70mm                                                 |
| 供电       | USB-C（支持 PD 快充）或外部 5V 电源                          |

### 3.2 软件特性

- **固件**：基于 FreeRTOS + 自研 OSAL，支持双核分工
- **PC 端 SDK**：Python/C++ API，支持 Windows/Linux/macOS
- **Lua 脚本引擎**：支持板载独立运行，可访问所有外设和文件系统
- **协议支持**：CMSIS-DAP、CDC、HID、MSC（U盘模式）、TCP/IP、MQTT、HTTP（后续）
- **兼容模式**：兼容 OpenOCD、PyOCD、Arduino IDE 等主流工具
