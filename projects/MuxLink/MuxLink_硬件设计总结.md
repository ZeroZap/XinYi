# MuxLink 硬件设计总结（V6.0）

## 1. 概述

MuxLink 是基于沁恒 CH32H417 双核 RISC-V 微控制器的多功能硬件调试与开发平台。通过 USB 3.0 连接 PC，集成了 CMSIS-DAP 调试器、双路高精度电流检测（0.1μA 到 10A）、完整 CDC 串口、大容量存储、HID 设备、SPI 接口 LCD 显示、TF 卡存储、以太网、USB PD 快充等功能。所有外设资源通过 OpenClaw 接口引出，支持用户自定义扩展。

## 2. 硬件架构

### 2.1 核心芯片：CH32H417

| 参数 | 规格 |
|------|------|
| 内核 | 双核 RISC-V：V5F@400MHz（大核），V3F@150MHz（小核） |
| 存储 | 896KB SRAM，960KB Flash |
| USB | USB 3.2 Gen1（5Gbps）、USB 2.0 HS（480Mbps）、USB 2.0 FS（12Mbps）、USB PD 控制器 |
| 以太网 | 10/100M MAC + PHY（内置） |
| 显示 | 支持 SPI 接口 LCD |
| 存储接口 | SDMMC（200MHz 双沿）、4×SPI、FMC（可选） |
| 模拟 | 双 12-bit ADC（5Msps）、20Msps 高速 ADC、双 12-bit DAC、运放、比较器 |
| 数字外设 | 8×UART、4×I²C、1×I3C、4×SPI、3×CAN、定时器组等 |
| 封装 | QFN128（95 个 GPIO） |
| 工作电压 | 3.3V（I/O 可配置 1.8V） |

### 2.2 USB 接口与复合设备

CH32H417 提供三个独立 USB 控制器：

- **USB FS 控制器**（12Mbps）：独立引脚 `USB2_FS_D±`，连接 Micro-USB 插座，用于早期开发调试
- **USB 3.0/HS 控制器**（5Gbps/480Mbps）：引脚 `USB3_D±`、`USB3_SS_TX±`、`USB3_SS_RX±` 连接 Type-C 插座
- **USB PD 控制器**：`CC1/CC2` 引脚直接连接 Type-C 插座，用于功率协商
- **SWD 调试接口**：引脚 `SWCLK/SWDIO` 通过跳线或 0Ω 电阻与 USB 3.0 的 `USB3_D±` 复用

### 2.3 电源树

```
[USB PD 输入 5-20V] ─┬─ [5V LDO] ── [3.3V LDO] ── CH32H417 核心
                     ├─ [可编程升降压] ── 目标板电源输出（1.8/2.5/3.3/5V）
                     └─ [INA229 电源] ── 3.3V
```

- **输入保护**：自恢复保险丝 + TVS 管
- **5V LDO**：USB 2.0 FS 接口供电
- **3.3V LDO**：MCU 及大部分数字电路供电
- **1.8V/1.2V LDO**：高速 GPIO 及 PLL 供电（可选）

### 2.4 电流检测电路

双 INA229 共享 SPI1 总线，配合 0.01Ω 和 1Ω 串联电阻及 MOSFET 旁路实现宽量程测量：

```
[电源输入] ──── 0.01Ω (2512 1W) ────┬──── 1Ω (1206 1/4W) ──── [负载]
                                    │
                                    └── [N-MOSFET SI2312] ──┘
                                           (G极接MCU GPIO)

INA229_0 (地址0x40) ── 测量0.01Ω两端
INA229_1 (地址0x41) ── 测量1Ω两端
```

- **小电流模式**（<100mA）：MOSFET 关断，INA229_1 测量 1Ω 电阻，功耗 <10mW
- **大电流模式**（>100mA）：MOSFET 导通，短路 1Ω，INA229_0 测量 0.01Ω
- **切换逻辑**：MCU 根据测量值动态控制 MOSFET，电流路径始终导通
- **硬件保护**：INA229_1 的 ALERT 引脚直接触发 MOSFET 导通，响应时间 <100μs

### 2.5 电平转换分组

48 个 GPIO 中，40 个引出至 OpenClaw，分为 5 组，每组独立电压配置：

| 组别 | 引脚范围 | 电平转换芯片 | 可配置电压 | 典型用途 |
|------|---------|------------|----------|---------|
| A | P1-P8 | TXS0108E | 1.8/2.5/3.3/5V | ADC、DAC、低速 GPIO |
| B | P9-P16 | SN74LVC8T245 | 1.8/2.5/3.3/5V | PWM、脉冲捕获 |
| C | P17-P24 | SN74LVC8T245 | 1.8/2.5/3.3/5V | SPI、UART |
| D | P25-P32 | TXS0108E | 1.8/2.5/3.3/5V | I2C、CAN |
| E | P33-P40 | SN74LVC8T245 | 1.8/2.5/3.3/5V | 高速 SPI、脉冲 |

每组电压通过跳线或 I²C 可编程电源模块设置。

### 2.6 存储电路

- **SPI Flash**（SPI3）：W25Q64（8MB），存储系统配置、OTA 备份固件。占用 SPI3 的 SCK, MOSI, MISO, CS 共 4 个引脚
- **TF 卡**（SDMMC）：使用 4 位模式，占用 CLK, CMD, D0-3 共 6 个引脚，用于用户数据存储（Lua 脚本、采集数据）

### 2.7 显示接口

采用 SPI2 驱动 LCD，典型连接如下：

| LCD 引脚 | 功能 | 连接方案 | 备注 |
|---------|------|--------|------|
| SCK | SPI 时钟 | SPI2_SCK | 建议 40MHz |
| MOSI | SPI 数据 | SPI2_MOSI | 仅写，MISO 可不接 |
| CS | 片选 | GPIO | 软件控制 |
| DC | 数据/命令 | GPIO | 必须 |
| RESET | 复位 | GPIO | 可与系统复位合并（可选） |
| BL | 背光 | GPIO（PWM） | 可调亮度 |

**引脚占用**：3-6 个（取决于是否使用 MISO/RESET）。性能：240×240@60fps 需约 6.9MB/s，SPI2 最大 40MHz 可满足。

### 2.8 以太网

内置 MAC+PHY，直接连接带网络变压器的 RJ45 插座（如 HR911105A），占用 4 个引脚（ETH_TX±, ETH_RX±）。

### 2.9 其他板载外设

- **调试串口**：UART0 连接板载 USB 转串口芯片（如 CH340N），占用 2 个引脚
- **板载 LED/按键**：2 个 GPIO

## 3. USB 复合设备设计

CH32H417 的 USB 3.0/HS 控制器和 USB FS 控制器分别有 16 个物理端点（EP0～EP15），且同一时刻端点是单向的。

### 3.1 FS/HS 共用核心配置（EP0-EP15）

| 物理端点 | 逻辑端点 | 方向 | 所属接口 | 功能描述 |
|---------|---------|------|---------|---------|
| EP0 | 0x00 | 双向 | 所有接口 | 控制传输 |
| EP1 | 0x01 OUT | OUT | 接口0 (Vendor) | CMSIS-DAP 命令发送 |
| EP2 | 0x82 IN | IN | 接口0 (Vendor) | CMSIS-DAP 响应接收 |
| EP3 | 0x83 IN | IN | 接口0 (Vendor) | CMSIS-DAP SWO 跟踪数据 |
| EP4 | 0x84 IN | IN | 接口1 (CDC1 Ctrl) | CDC1 状态通知（中断） |
| EP5 | 0x05 OUT | OUT | 接口2 (CDC1 Data) | CDC1 数据 OUT |
| EP6 | 0x86 IN | IN | 接口2 (CDC1 Data) | CDC1 数据 IN |
| EP7 | 0x87 IN | IN | 接口3 (CDC2 Ctrl) | CDC2 状态通知（中断） |
| EP8 | 0x08 OUT | OUT | 接口4 (CDC2 Data) | CDC2 数据 OUT |
| EP9 | 0x89 IN | IN | 接口4 (CDC2 Data) | CDC2 数据 IN |
| EP10 | 0x0A OUT | OUT | 接口5 (MSC) | MSC 数据 OUT |
| EP11 | 0x8B IN | IN | 接口5 (MSC) | MSC 数据 IN |
| EP12 | 0x8C IN | IN | 接口6 (HID) | HID 数据 IN |
| EP13 | 0x0D OUT | OUT | 接口6 (HID) | HID 数据 OUT（可选） |
| EP14-15 | - | - | 备用 | 未来扩展 |

**接口组合**（通过 IAD）：
- 接口1 + 接口2 → 完整 CDC1
- 接口3 + 接口4 → 完整 CDC2
- 接口0 → 独立 Vendor 类（CMSIS-DAP v2）
- 接口5 → 独立 MSC 类（U盘模式）
- 接口6 → 独立 HID 类

### 3.2 FS 阶段独享功能

FS 模式下，由于有独立的 USB FS 控制器，可以启用上述所有 16 个端点，实现完整的 **CMSIS-DAP + 双CDC + MSC + HID**。

### 3.3 HS 阶段功能集

HS 模式下（使用 USB 3.0/HS 控制器），同样支持上述配置，但实际应用中可根据需要选择启用全部或部分功能。由于 HS 速度远高于需求，可保留全部功能，实现与 FS 阶段完全一致的复合设备描述符。

### 3.4 描述符关键参数

| 参数 | FS 模式 | HS 模式 | USB3.0 模式 |
|------|--------|--------|-----------|
| bcdUSB | 0x0200 | 0x0200 | 0x0300 |
| 批量端点最大包长 | 64 | 512 | 1024 |
| 中断端点最大包长 | 64 | 64 | 1024（可选） |
| 端点总数 | 16 | 16 | 16 |

### 3.5 速度自动协商

CH32H417 硬件自动完成速度协商：
- 插入 USB3.0 端口 → 进入 SuperSpeed 模式（5Gbps）
- 插入 USB2.0 HS 端口 → 进入高速模式（480Mbps）
- 插入 USB1.1 FS 端口 → 进入全速模式（12Mbps）

固件通过读取 `USBHSD->MIS_ST` 寄存器获取当前速度，必要时调整端点最大包长。

## 4. 双核分工与固件架构

| 核心 | 负责任务 |
|------|---------|
| **大核 (V5F@400MHz)** | USB 协议栈（处理 EP0-EP15）、CMSIS-DAP 协议、数据流打包解包、核间通信管理 |
| **小核 (V3F@150MHz)** | 实时数据采集（双 INA229、ADC）、SPI2 LCD 刷新、TF 卡文件系统、以太网协议栈、升降压 I²C 控制 |

**核间通信**：
- 通过共享内存（896KB SRAM 中划分 256KB）实现数据交换
- 使用 Mailbox 机制同步，避免竞争

**固件分层**：

```
┌─────────────────┐
│  应用层（Lua脚本）│
├─────────────────┤
│  服务层（文件系统、协议栈、用户API）│
├─────────────────┤
│   OSAL（资源管理、核间通信、设备抽象） │
├─────────────────┤
│   HAL（硬件抽象层：GPIO、SPI、I2C、TIM等） │
├─────────────────┤
│   硬件（CH32H417 + 外设） │
└─────────────────┘
```

## 5. IO 资源占用总表

| 功能模块 | 接口/外设 | 占用 GPIO 数 | 备注 |
|---------|---------|-----------|------|
| 以太网 | ETH（内置 PHY） | 4 | ETH_TX±, ETH_RX± |
| USB 3.0 | USB3_D±, SSTX±, SSRX± | 6 | 专用高速引脚 |
| USB FS | USB2_FS_D± | 2 | 独立调试接口 |
| 调试接口 | SWDIO, SWCLK | 2 | 固件烧录与调试 |
| 调试串口 | UART0 TX/RX | 2 | 连接板载 USB 转串口芯片 |
| SPI Flash（SPI3） | W25Q64 | 4 | SCK, MOSI, MISO, CS |
| TF 卡 | SDMMC | 6 | CLK, CMD, D0-3 |
| SPI LCD（SPI2） | SPI2 + 控制 | 4-6 | SCK, MOSI, CS, DC, RST, BL |
| 双 INA229（SPI1） | SPI1 + 2×CS + 2×ALERT | 7 | 共享总线 + 片选 + 中断 |
| 升降压 I2C | I2C0 | 2 | SCL, SDA |
| 升降压 EN/PG | GPIO | 2 | 使能、电源状态 |
| 板载 LED/按键 | GPIO | 2 | 用户指示灯、按钮 |
| **总计占用** | | **45-47** | 约占总 GPIO 的 49% |

### 剩余 GPIO

- **剩余 GPIO 数量**：95 – 47 = **48 个**
- 其中 **40 个** 通过 **OpenClaw 40pin 连接器**引出
- 剩余 **8 个** 备用，可用于板载测试点或未来功能增强

## 7. 机械与 PCB 设计要点

- **尺寸**：100mm × 70mm（暂定）
- **层数**：4 层板（信号、地、电源、信号）
- **关键布线**：
  - USB 3.0 差分对（SSTX±、SSRX±）严格等长、阻抗 90Ω
  - SPI 时钟线尽量短，减少反射
  - INA229 采样电阻采用开尔文连接
- **接口布局**：
  - 左侧：USB-C（HS/PD）、USB Micro-B（FS）、RJ45
  - 右侧：OpenClaw 40pin 连接器
  - 上方：TF 卡座、LCD 接口
  - 下方：电源端子、按键、LED

## 9. 总结

经过多轮研讨与优化，MuxLink 的最终硬件设计实现了：

- **极致的 IO 效率**：板载功能仅占用 47 个 GPIO，剩余 **48 个** 可供用户自由配置，其中 40 个通过 OpenClaw 引出
- **灵活的显示方案**：SPI LCD 替代 LTDC，节省大量引脚，性能满足 60fps
- **丰富的板载功能**：调试器、双路高精度电流、双 CDC、MSC、HID、以太网、TF 卡、可调电源
- **双核并行架构**：400MHz + 150MHz 分工协作，保障高性能与实时性
- **USB 3.0 高速传输**：实测 450MB/s，大幅超越 H7-TOOL 等同类产品

MuxLink 不仅是一款调试工具，更是一个开放的、可扩展的硬件开发平台，将成为嵌入式工程师的"万能实验室"。
