# MuxLink 软件设计总结

## 产品定位与愿景

MuxLink 是一款面向嵌入式开发者、硬件工程师、创客、教育机构和科研实验室的**多功能硬件调试与开发平台**。

**核心理念**：
- **软件定义硬件**：同一套硬件通过 PC 端软件或板载 Lua 脚本，可随时变身为不同的仪器
- **模块化扩展**：通过 OpenClaw 接口连接各种外设模块，自由组合功能
- **开发者友好**：从 Arduino 兼容层到自研 OSAL 框架，再到 AI 辅助开发

**品牌口号**：
- 主口号：*One Link, Infinite Links*（一个连接，无限可能）
- 副口号：*Your Hardware Lab in a Dongle*（装在 U 盘里的硬件实验室）

## 集成功能

### 调试与分析
- **CMSIS-DAP v2 调试器**：支持 SWD/JTAG，调试速度 > 10MHz
- **双路高精度电流分析仪**：0.1μA ~ 10A，20-bit 分辨率
- **逻辑分析仪**：通过 OpenClaw GPIO 扩展
- **协议转换器**：支持多种通信协议

### 通信接口
- **虚拟串口**：2 路完整 CDC（每路带中断端点）
- **以太网**：百兆自适应（内置 PHY）
- **USB 3.0**：5Gbps 高速传输（实测 > 400MB/s）

### 电源与测量
- **可编程电源**：USB PD 输入（5-20V），板载可调输出（1.8V-5V）
- **电源分析**：实时功耗监测、电流曲线记录

### 显示与存储
- **LCD 显示**：2.4 英寸 240×240 RGB LCD，电容触摸
- **TF 卡存储**：支持 FatFS，用户数据存储
- **板载 Flash**：8MB QSPI Flash（系统配置、OTA 固件）

### 扩展接口
- **OpenClaw 40pin**：引出 27 个 GPIO，可配置为 ADC/DAC/PWM/UART/I2C/SPI

## 固件架构

### 分层设计

```
┌─────────────────────────────┐
│   应用层（Lua 脚本引擎）      │
├─────────────────────────────┤
│ 服务层（文件系统、协议栈、API）│
├─────────────────────────────┤
│ OSAL（资源管理、核间通信、抽象）│
├─────────────────────────────┤
│ HAL（GPIO、SPI、I2C、TIM 等）  │
├─────────────────────────────┤
│ 硬件（CH32H417 + 外设）       │
└─────────────────────────────┘
```

### 双核分工

| 核心 | 频率 | 职责 |
|------|------|------|
| **大核** | 400MHz | USB 协议栈、CMSIS-DAP 协议、数据流打包解包、核间通信管理 |
| **小核** | 150MHz | 实时数据采集（INA229、ADC）、SPI2 LCD 刷新、TF 卡文件系统、以太网协议栈、升降压 I²C 控制 |

**核间通信**：
- 共享 256KB SRAM 实现数据交换
- Mailbox 机制同步，避免竞争

### 基础框架
- **RTOS**：FreeRTOS + 自研 OSAL
- **USB 协议栈**：支持 CMSIS-DAP v2、CDC、HID、MSC
- **文件系统**：FatFS（TF 卡）+ SPIFFS（Flash）

## 软件特性

### PC 端 SDK
- **语言支持**：Python / C++ API
- **平台支持**：Windows / Linux / macOS
- **功能**：
  - 调试控制（SWD/JTAG）
  - 电流数据采集
  - 串口通信
  - 文件传输
  - 远程脚本执行

### Lua 脚本引擎
- **独立运行**：板载 Lua 虚拟机，无需 PC
- **外设访问**：可访问所有外设和文件系统
- **应用场景**：
  - 自动化测试脚本
  - 数据处理与分析
  - 设备控制与监测
  - 定时任务

### 协议支持
- **调试**：CMSIS-DAP、OpenOCD、PyOCD
- **通信**：CDC、HID、MSC（U 盘模式）
- **网络**：TCP/IP、MQTT、HTTP（后续）
- **兼容**：Arduino IDE、主流开发工具

| 竞争对手 | 优势 | 劣势 | MuxLink 差异化 |
