# AI 代码审查清单

## 自动检查项

### 🔧 代码质量
- [ ] 函数长度 ≤ 50 行
- [ ] 圈复杂度 ≤ 10
- [ ] 嵌套深度 ≤ 4 层
- [ ] 无重复代码块 (>10行)
- [ ] 无魔法数字

### 📝 文档完整性
- [ ] 文件头注释完整
- [ ] 公共函数有 Doxygen 注释
- [ ] 复杂算法有说明注释
- [ ] README 已更新

### 🔒 安全性
- [ ] 无禁用函数
- [ ] 指针使用前检查
- [ ] 内存正确释放
- [ ] 无缓冲区溢出风险

### ⚡ 性能
- [ ] 无不必要的内存分配
- [ ] 循环内无重复计算
- [ ] 大数据结构使用指针传递
