### 3. 设计模式系列

#### 《设计模式：可复用面向对象软件基础》(GoF)
**23 种设计模式分类**:

**创建型模式 (5 种)**:
| 模式 | 意图 | 应用场景 |
|------|------|---------|
| Abstract Factory | 创建相关对象族 | UI 组件库 |
| Builder | 分步构建复杂对象 | 配置构建器 |
| Factory Method | 定义创建接口 | 日志工厂 |
| Prototype | 通过复制创建 | 对象池 |
| Singleton | 保证唯一实例 | 配置管理器 |

**结构型模式 (7 种)**:
| 模式 | 意图 | 应用场景 |
|------|------|---------|
| Adapter | 接口转换 | 遗留系统适配 |
| Bridge | 抽象与实现分离 | 跨平台 GUI |
| Composite | 树形结构 | 文件系统 |
| Decorator | 动态添加职责 | IO 流 |
| Facade | 提供统一接口 | 子系统入口 |
| Flyweight | 共享细粒度对象 | 字符渲染 |
| Proxy | 控制访问 | 远程代理 |

**行为型模式 (11 种)**:
| 模式 | 意图 | 应用场景 |
|------|------|---------|
| Chain of Responsibility | 传递请求 | 事件处理链 |
| Command | 封装请求 | 命令队列 |
| Interpreter | 定义文法 | 脚本引擎 |
| Iterator | 顺序访问 | 集合遍历 |
| Mediator | 集中控制 | 聊天室 |
| Memento | 保存状态 | 撤销操作 |
| Observer | 一对多依赖 | 事件系统 |
| State | 状态改变行为 | 状态机 |
| Strategy | 定义算法族 | 排序策略 |
| Template Method | 定义骨架 | 框架钩子 |
| Visitor | 操作元素 | 编译器 AST |

#### 《HeadFirst 设计模式》
**特点**:
- 图文并茂，易于理解
- 大量实例代码
- 适合初学者

#### 《图解设计模式》(结城浩)
**特点**:
- 日式图解风格
- 循序渐进
- 配有 UML 图

### 5. C 语言编程系列

#### 《C Primer Plus》(第 6 版)
**核心内容**:
- C 语言基础语法
- 数据类型与运算符

- 数组与字符串
- 结构体与联合体
- 文件 I/O
- C 标准库

**适合人群**: C 语言初学者

#### 《C 标准》系列
**C89/C90**:
- 第一个 ANSI/ISO 标准
- 基础语法定义
- 标准库定义

**C99**:
- 新增特性最多
- 变长数组 (VLA)
- 复数支持
- 布尔类型
- inline 函数
- restrict 指针

**C11**:
- 多线程支持 (_Thread_local, _Atomic)
- 泛型选择 (_Generic)
- 静态断言 (_Static_assert)
- 匿名结构体/联合体

**C17/C18**:
- Bug 修复
- 技术修正
- 无新特性

#### 《Effective C++》
**55 条具体建议** (C++ 但部分适用于 C):
- 构造/析构/赋值
- 资源管理
- 类设计
- 继承
- 模板

#### 《代码整洁之道》(Clean Code)
**核心原则**:
1. **有意义的命名**
   - 名副其实
   - 避免误导
   - 做有意义的区分

2. **函数设计**
   - 短小
   - 只做一件事
   - 参数少于 3 个

3. **注释原则**
   - 注释不能美化代码
   - 用代码表达意图
   - 好的注释说明 Why

4. **格式规范**
   - 垂直格式化
   - 水平格式化
   - 团队统一风格

5. **错误处理**
   - 使用异常而非返回码
   - 提供上下文信息
   - 定义异常类

### 6. 代码规范系列

#### 《SEI CERT C Coding Standard》
**核心规则分类**:

**PRE (预处理器)**:
- PRE00-C: 避免复杂宏
- PRE01-C: 宏参数加括号
- PRE06-C: 条件表达式无副作用

**DCL (声明)**:
- DCL00-C: 避免隐藏外部作用域
- DCL02-C: 不使用 VLAs

**EXP (表达式)**:
- EXP00-C: 无副作用的序列点
- EXP03-C: sizeof 操作数无副作用
- EXP05-C: 整数转换不丢失信息

**MEM (内存管理)**:
- MEM00-C: 正确分配内存
- MEM01-C: 释放后不访问
- MEM02-C: 释放后立即置 NULL
- MEM03-C: 动态分配内存清零

**FIO (文件 I/O)**:
- FIO00-C: 不操作未打开文件
- FIO02-C: 验证 fopen 返回值

**CON (并发)**:
- CON32-C: 防止位域数据竞争
- CON36-C: 原子操作原语

#### 《ANSSI Secure C Language Guide》
**法国国家安全机构发布的 C 语言安全指南**:
- 安全编码规则
- 常见漏洞预防
- 静态分析规则

### 7. 版本规范系列

#### 《语义化版本 2.0.0》
**版本格式**: `X.Y.Z` (主版本号。次版本号。修订号)

**规则**:
1. 主版本号 (X): 不兼容的 API 修改
2. 次版本号 (Y): 向下兼容的功能新增
3. 修订号 (Z): 向下兼容的问题修正

**示例**:
```
1.0.0  - 初始版本
1.0.1  - Bug 修复
1.1.0  - 新增功能 (向下兼容)
2.0.0  - 不兼容的 API 变更
```

#### 《宏定义版本控制规范》
**版本宏定义**:
```c
#define VERSION_MAJOR 1
#define VERSION_MINOR 0
#define VERSION_PATCH 0

/* 组合版本 */
#define VERSION ((VERSION_MAJOR << 16) | \
                 (VERSION_MINOR << 8)  | \
                 (VERSION_PATCH))

/* 版本字符串 */
#define VERSION_STRING "1.0.0"
```
