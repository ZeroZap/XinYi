# XinYi Change Log

This is the canonical release-note source for XinYi framework releases. Historical reports under
`docs/history/` are archival evidence and must not be used to generate a new release.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
Semantic Versioning.
