## 概述

本指南整合了 XinYi 项目的所有代码风格约定。遵循 RFC2119/RFC8174 标准，其中 **MUST**、**SHOULD**、**MAY** 和 **OPTIONAL** 具有特定含义。

## 1. 一般规则

### 1.1 语言标准
- **必须** 使用 C99 标准
- **禁止** 使用制表符，使用空格代替
- **必须** 每级缩进使用 4 个空格

### 1.2 空格规则
- **必须** 在关键字和左括号之间使用 1 个空格：`if (condition)`, `while (condition)`, `for (init; condition; step)`
- **禁止** 在函数名和左括号之间使用空格：`sum(4, 3)` ✓, `sum (4, 3)` ✗
- **必须** 在比较和赋值运算符前后使用单个空格：`a = 3 + 4;` ✓
- **必须** 在每个逗号后使用单个空格：`func_name(5, 4);` ✓

**示例**:
```c
/* 正确的空格 */
if (x > 0) {
    int32_t result = calculate(a, b, c);
    for (size_t i = 0; i < 10; ++i) {
        array[i] = i * 2;
    }
}

/* 错误的空格 */
if(x>0){                    /* 缺少空格 */
    int32_t result=calculate(a,b,c);
    for(size_t i=0;i<10;++i){
        array[i]=i*2;
    }
}
```

### 1.3 命名约定
- **禁止** 使用 `__` 或 `_` 前缀用于变量/函数/宏/类型（C 语言保留）
- **必须** 仅使用小写字母用于变量/函数/类型，可选下划线 `_`
- **应该** 对严格的模块私有（静态）函数使用 `prv_` 前缀
- **应该** 对跨模块使用的库内部函数使用 `libname_int_` 或 `libnamei_` 前缀
- **应该** 对外部函数使用 `module_get_xxx` 或 `module_set_xxx` 命名

**示例**:
```c
/* 正确的命名 */
static void prv_initialize_buffer(void);           /* 私有函数 */
void battery_get_voltage(uint16_t* voltage);       /* 公共 getter */
void battery_set_threshold(uint16_t threshold);    /* 公共 setter */
static int32_t battery_int_calculate_soc(void);    /* 内部函数 */

/* 错误的命名 */
static void _initialize_buffer(void);              /* 保留前缀 */
void __battery_get_voltage(void);                  /* 保留前缀 */
void BatteryGetVoltage(void);                      /* 混合大小写 */
void battery_get_VOLTAGE(void);                    /* 混合大小写 */
```

### 1.4 括号和块
- **必须** 将左花括号放在与关键字同一行：`for (i = 0; i < 5; ++i) { }` ✓
- **必须** 为所有复合语句包含括号，即使单条语句：`if (c) { do_a(); }` ✓
- **必须** 为每个块级别使用单个缩进

## 2. 变量

### 2.1 声明规则
- **必须** 在同一行声明相同类型的所有局部变量：`char a, b;` ✓
- **必须** 在块的开头、第一个可执行语句之前声明局部变量
- **必须** 按顺序声明变量：
  1. 自定义结构和枚举
  2. 整数类型（宽的无符号优先：uint32_t, int32_t, uint16_t, int16_t, char）
  3. 单/双精度浮点

### 2.2 变量使用
- **必须** 使用 `size_t` 用于长度或大小变量
- **必须** 如果函数不应修改指向的内存，对指针使用 `const`
- **必须** 对不应修改的函数参数或变量使用 `const`
- **必须** 总是将指针与 `NULL` 比较
- **必须** 总是将变量与零比较，除非作为布尔值处理：`if (length > 0)` ✓, `if (is_ok)` ✓
- **应该** 使用前自增而不是后自增：`++a` ✓ 而不是 `a++`
- **禁止** 使用可变长度数组 (VLA)；使用 `malloc()` 和 `free()` 代替
- **禁止** 将全局变量初始化为默认值；在专用的 `init` 函数中实现

### 2.3 指针使用
- **必须** 当函数接受任何类型的指针时使用 `void*`
- **禁止** 转换 `malloc()` 或 `void*` 函数的返回值
- **必须** 如果函数不应修改指向的内存，使用 `const void*`

### 2.4 布尔处理
- **禁止** 使用 `stdbool.h`；使用 1 或 0 代替
- **禁止** 将布尔变量与 1 比较：`if (is_ok == 1)` ✗
- **必须** 使用 `!` 进行否定布尔检查：`if (!is_ok)` ✓

## 3. 函数

### 3.1 函数声明
- **必须** 为所有模块外可访问的函数提供函数原型
- **必须** 使用小写函数名，可选下划线：`my_func()` ✓, `MYFunc()` ✗
- **必须** 将星号与返回类型对齐用于指针返回：`const char* my_func(void);` ✓
- **应该** 对齐具有相似功能的函数原型以提高可读性

### 3.2 函数实现
- **必须** 在与函数名同一行包含返回类型和可选关键字
- **必须** 为每个函数包含 doxygen 文档，即使静态函数
- **必须** 对函数、变量和注释使用英文名称/文本

### 3.3 函数参数
- **必须** 对不应修改的参数使用 `const`
- **必须** 在文档中用 `[in]` 标记输入参数，用 `[out]` 标记输出参数

## 4. 结构体、枚举和类型定义

### 4.1 命名规则
- **必须** 使用小写名，可选下划线
- **必须** 仅对 typedef'd 结构体/枚举使用 `_t` 后缀
- **禁止** 对没有 typedef 的命名结构体使用 `_t` 后缀

### 4.2 结构体声明模式

**模式 1：仅命名结构体（无 typedef）**
```c
struct struct_name {
    char* a;
    char b;
};
```

**模式 2：仅 typedef（匿名结构体）**
```c
typedef struct {
    char* a;
    char b;
} struct_name_t;
```

**模式 3：命名结构体带 typedef**
```c
typedef struct struct_name {    /* 无 _t 后缀 */
    char* a;
    char b;
} struct_name_t;                /* _t 后缀 */
```

### 4.3 结构体初始化
- **必须** 使用 C99 指定初始化器风格：`.a = 1, .b = 2`
- **应该** 为复杂结构体在最后一个元素后添加尾随逗号（帮助 clang-format）
- **必须** 在单独的行声明每个成员

### 4.4 枚举规则
- **必须** 对枚举成员使用全大写：`MY_ENUM_VALUE` ✓
- **必须** 对 typedef'd 枚举使用 `_t` 后缀
- **必须** 包含 doxygen 文档

### 4.5 函数指针类型定义
- **必须** 对函数指针类型定义使用 `_fn` 后缀：
```c
typedef uint8_t (*my_func_typedef_fn)(uint8_t p1, const char* p2);
```

## 5. 宏和预处理器

### 5.1 宏命名和保护
- **必须** 使用全大写名，可选下划线：`MY_MACRO` ✓
- **必须** 括号所有参数：`#define MIN(x, y) ((x) < (y) ? (x) : (y))` ✓
- **必须** 括号整个宏表达式：`#define SUM(x, y) ((x) + (y))` ✓
- **禁止** 多次评估有副作用的参数

### 5.2 多语句宏
- **必须** 将多语句宏包装在 `do { } while (0)` 中：
```c
#define SET_POINT(p, x, y) do { (p)->px = (x); (p)->py = (y); } while (0)
```

### 5.3 常用宏
```c
#define XY_MIN(x, y)        ((x) < (y) ? (x) : (y))
#define XY_MAX(x, y)        ((x) > (y) ? (x) : (y))
#define XY_BIT(pos)         (1UL << (pos))
#define XY_ARRAY_SIZE(arr)  (sizeof(arr) / sizeof((arr)[0]))
#define XY_CLAMP(v, min, max) (((v) < (min)) ? (min) : (((v) > (max)) ? (max) : (v)))
#define XY_UNUSED(x)        do { (void)(x); } while (0)
```

### 5.4 条件编译
- **必须** 使用 `defined()` 或 `!defined()` 代替 `#ifdef` 或 `#ifndef`
- **必须** 文档化所有 `#if/#elif/#else/#endif` 语句：
```c
#if defined(XYZ)
    /* 如果 XYZ 已定义则执行 */
#else /* defined(XYZ) */
    /* 如果 XYZ 未定义则执行 */
#endif /* !defined(XYZ) */
```
- **禁止** 在 `#if` 块内缩进子语句

### 5.5 宏与内联函数
- **应该** 对于超过 1-2 个操作的逻辑，优先使用 `static inline` 函数而不是宏
- **应该** 当需要类型安全时，优先使用 `static inline` 函数

## 6. 注释

### 6.1 注释风格
- **禁止** 使用 `//` 注释
- **必须** 对单行注释使用 `/* simple comment. */`
- **必须** 对结构体成员注释使用 `/**< member comment */`
- **必须** 对多行注释每行使用 `空格 + 星号`：
```c
/*
 * 这是多行注释
 * 写在 2 行（可以）
 */
```

### 6.2 注释对齐
- **应该** 从行首开始在 12 个缩进级别（12 * 4 空格）对齐注释
- **应该** 如果语句超过 12 个缩进，对齐到下一个可用的 4 空格缩进

## 7. 复合语句

### 7.1 If/Else 语句
- **必须** 为所有复合语句包含括号
- **必须** 将 `else` 放在 `if` 的右括号同一行：`} else {` ✓
- **必须** 对链式条件使用 `else if`

### 7.2 Do-While 语句
- **必须** 将 `while` 放在右括号同一行：`} while (condition);` ✓

### 7.3 空循环
- **必须** 对空循环使用空单行括号：`while (condition) {}` ✓
- **禁止** 在空括号内使用空格：`while (condition) { }` ✗

### 7.4 循环偏好
- **应该** 优先使用 `for` 循环而不是 `while` 循环
- **应该** 优先使用 `while` 循环而不是 `do-while` 循环
- **应该** 在可能时在 `for` 语句中声明循环计数器：`for (size_t i = 0; i < 10; ++i)`

### 7.5 三元运算符
- **应该** 仅对赋值或函数调用使用三元运算符
- **禁止** 用于没有赋值的函数调用：`condition ? func_a() : func_b();` ✗

## 8. Switch 语句

### 8.1 Switch 结构
- **必须** 将每个 `case` 语句缩进单个缩进
- **必须** 将 `case` 内的语句缩进额外的缩进
- **必须** 将 `break` 语句缩进额外的缩进
- **必须** 总是包含 `default` 分支

### 8.2 带局部变量的 Switch
- **必须** 对需要局部变量的 `case` 块使用括号
- **必须** 将左括号放在与 `case` 同一行：`case 0: {` ✓
- **必须** 将 `break` 放在括号内

```c
switch (a) {
    case 0: {
        int32_t a, b;
        a = 5;
        break;
    }
    default:
        break;
}
```

## 9. 文档 (Doxygen)

### 9.1 文件文档
- **必须** 在文件开头包含 doxygen `\file` 和 `\brief`
- **必须** 包含许可证头（单星号，不是双星号）
- **必须** 在文件头后留空行

### 9.2 函数文档
- **必须** 包含 `\brief` 描述
- **必须** 用 `\param[in]` 或 `\param[out]` 文档化所有参数
- **必须** 对非 void 函数包含 `\return`
- **应该** 对额外信息使用 `\note` 或 `\warning`
- **必须** 在参数名和描述之间使用冒号：`\param[in] a: 第一个数字`

### 9.3 宏文档
- **必须** 对宏文档包含 `\hideinitializer` 命令

### 9.4 结构体/枚举文档
- **必须** 对成员文档使用 `/**< member comment */`
- **必须** 对结构体和枚举遵循 doxygen 语法

## 10. 头文件和源文件

### 10.1 头文件规则
- **必须** 包含包含保护：`#ifndef XY_FILE_H`
- **必须** 包含 C++ extern 检查：
```c
#ifdef __cplusplus
extern "C" {
#endif
```
- **必须** 仅包含编译所需的头文件
- **必须** 仅暴露公共模块变量/类型/函数
- **必须** 对全局模块变量使用 `extern`
- **禁止** 包含模块私有声明
- **必须** 在文件末尾留空行

### 10.2 源文件规则
- **必须** 首先包含对应的头文件
- **禁止** 在其他 `.c` 文件中包含 `.c` 文件
- **必须** 在文件末尾留空行

### 10.3 包含顺序
1. 标准 C 库头文件
2. 应用程序自定义头文件

## 11. 快速参考检查清单

- [ ] 使用 C99 标准
- [ ] 每级 4 空格，无制表符
- [ ] 小写名，可选下划线
- [ ] 用户代码无 `__` 或 `_` 前缀
- [ ] 关键字后空格：`if (`, `while (`
- [ ] 函数名后无空格：`func(`
- [ ] 括号与关键字同行
- [ ] 所有复合语句使用括号
- [ ] 对不可变指针/参数使用 `const`
- [ ] 对长度/大小使用 `size_t`
- [ ] 对指针比较使用 `NULL`
- [ ] 对数值比较使用 `> 0` 或 `== 0`
- [ ] `/* */` 注释，无 `//`
- [ ] 所有函数的 Doxygen 文档
- [ ] 仅对 typedef'd 类型使用 `_t` 后缀
- [ ] 括号宏参数和表达式
- [ ] 对多语句宏使用 `do { } while (0)`
- [ ] 对条件编译使用 `defined()`
- [ ] 文档化 `#if/#endif` 块
- [ ] 文件末尾空行
