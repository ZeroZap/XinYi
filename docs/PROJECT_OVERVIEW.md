## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/ZeroZap/XinYi.git
cd XinYi
```

### 2. 构建项目

```bash
mkdir build && cd build
cmake .. -DBUILD_TESTING=ON
make -j$(nproc)
```

### 3. 运行测试

```bash
make test
```

### 4. 开始开发

```c
#include "xy.h"

int main(void) {
    xy_os_kernel_init();
    xy_log_i("Hello XinYi!\n");
    xy_os_kernel_start();
    return 0;
}
```
