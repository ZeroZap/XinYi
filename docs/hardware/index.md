## 📖 移植指南

### 移植到新 MCU

1. **创建 MCU 目录**
   ```
   components/hal/<mcu_series>/
   ```

2. **实现 HAL 接口**
   - 复制参考实现
   - 实现所有 `xy_hal_*.c` 文件

3. **配置构建系统**
   ```cmake
   # CMakeLists.txt
   add_subdirectory(components/hal/<mcu_series>)
   ```

4. **测试验证**
   - 运行单元测试
   - 硬件在环测试
