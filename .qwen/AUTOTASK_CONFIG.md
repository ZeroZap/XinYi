# Agent 自主任务调度器

**版本**: 1.0  
**最后更新**: 2026-03-01  
**触发条件**: 半小时无用户交互自动执行

---

## 📋 功能说明

### 自主任务类型

1. **TODO 执行**: 执行待办任务列表中的任务
2. **自主学习**: 学习新知识并整理到文档
3. **代码优化**: 重构/优化现有代码
4. **文档完善**: 补充缺失的文档
5. **测试补充**: 添加单元测试

### 触发条件

- **空闲检测**: 30 分钟无用户交互
- **任务队列**: TODO 列表非空
- **可被中断**: 用户新消息立即停止

### 控制命令

| 命令 | 说明 |
|------|------|
| `/autotask start` | 启动自主任务 |
| `/autotask stop` | 停止自主任务 |
| `/autotask pause` | 暂停自主任务 |
| `/autotask resume` | 恢复自主任务 |
| `/autotask status` | 查看状态 |
| `/autotask set_timeout 30` | 设置超时 (分钟) |

---

## 🔧 配置

```yaml
autotask:
  enabled: true
  idle_timeout_minutes: 10  # 已执行 autotask set_timeout 10
  max_run_time_minutes: 60
  task_types:
    - todo
    - learn
    - optimize
    - docs
    - test
  exclude_hours:  # 排除时间段 (24 小时制)
    - start: 23
    - end: 7
```

## 🚨 注意事项

1. **不打扰用户**: 用户活动时自动暂停
2. **可中断**: 用户新消息立即停止
3. **保存进度**: 任务中断时保存状态
4. **报告生成**: 每次运行生成报告
5. **时间限制**: 排除深夜时段 (23:00-7:00)
