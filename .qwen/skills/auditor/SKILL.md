# 代码审计员 Skill

**名称**: auditor

**角色**: 代码质量审查、安全审计、规范检查

**职责**:
- 代码审查
- 规范检查
- 安全审计
- 性能分析
- 质量报告

---

## 使用方式

```bash
# 请求代码审查
/skill auditor review <component>

# 查看审计报告
/skill auditor report

# 查看规范检查
/skill auditor specs

# 生成质量报告
/skill auditor quality
```

---

## 审查流程

### 1. 代码接收

从开发人员接收待审查代码：
```bash
/skill auditor review crypto
```

### 2. 自动检查

运行自动化工具：
```bash
# 代码风格检查
clang-format --dry-run src/*.c

# 静态分析
clang-tidy src/*.c

# 编译检查
make -Werror
```

### 3. 手动审查

审查要点：
- [ ] 代码规范遵循
- [ ] 错误处理完善
- [ ] 边界条件处理
- [ ] 内存管理正确
- [ ] 并发安全
- [ ] 文档完整

### 4. 审查报告

生成审查报告：
```bash
/skill auditor report
```

---

## 审查清单

### 代码规范

- [ ] 4 空格缩进（无制表符）
- [ ] 小写 + 下划线命名
- [ ] 括号与关键字同行
- [ ] 函数有 Doxygen 注释
- [ ] 使用 xy_log_*() 日志
- [ ] 行宽 < 100 字符

### 错误处理

- [ ] 检查所有返回值
- [ ] 使用标准化错误码
- [ ] 错误日志记录
- [ ] 资源释放处理

### 内存安全

- [ ] 无内存泄漏
- [ ] 指针使用前检查
- [ ] 数组边界检查
- [ ] 无缓冲区溢出

### 并发安全

- [ ] 共享资源加锁
- [ ] 中断安全处理
- [ ] 无死锁风险
- [ ] 原子操作使用正确

### 性能

- [ ] 无低效循环
- [ ] 内存分配合理
- [ ] 缓存友好
- [ ] 中断处理快速

## 自动化工具

### clang-format 检查

```bash
# 检查代码风格
clang-format --dry-run --Werror src/*.c

# 自动格式化
clang-format -i src/*.c
```

### clang-tidy 检查

```bash
# 运行静态分析
clang-tidy src/*.c -- \
    -Iinclude \
    -DSTM32U5 \
    -std=c99
```

### Cppcheck 检查

```bash
# 运行检查
cppcheck --enable=all --std=c99 src/
```

## 常见问题

### 严重问题

- 内存泄漏
- 缓冲区溢出
- 空指针解引用
- 整数溢出

### 中等问题

- 错误处理缺失
- 资源未释放
- 边界条件未处理

### 轻微问题

- 代码风格问题
- 注释缺失
- 命名不规范
