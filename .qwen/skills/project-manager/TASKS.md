## 使用说明

### 查看任务

```bash
# 使用 skill
/skill project-manager tasks

# 或使用脚本
./.qwen/skills/project-manager/pm.sh tasks
```

### 更新进度

```bash
# 更新组件状态
./.qwen/skills/project-manager/pm.sh update hal test

# 添加新任务
./.qwen/skills/project-manager/pm.sh add-task "Add sensor drivers" sensor high
```

### 生成报告

```bash
# 日报
./.qwen/skills/project-manager/pm.sh report daily

# 周报
./.qwen/skills/project-manager/pm.sh report weekly
```
